# Product

## Register

product

## Platform

web

## Users

Indonesian Muslims who need accurate daily prayer times for their location. Users check the app throughout the day to know when to pray — quick lookups, low-friction, likely on mobile.

## Product Purpose

Display accurate prayer schedules (Subuh, Dhuhur, Ashar, Maghrib, Isya) for cities in Indonesia using astronomical calculations. The app calculates times based on latitude, longitude, elevation, and timezone — no external API dependencies.

## Positioning

Accurate prayer time calculations using established astronomical formulas. The value is mathematical precision, not features.

## Brand Personality

Clean, functional, no-nonsense. The interface should be invisible — users come for the times, not the design.

## Anti-references

- Cluttered interfaces with excessive information
- Generic Bootstrap/template designs (the current Miniport template is already dated)
- Flashy animations or unnecessary visual noise
- Over-featured apps that obscure the core function

## Design Principles

1. **Utility first** — every element serves the prayer time display
2. **Speed** — instant page load, no JS bloat
3. **Accuracy** — calculations are the product; display them clearly
4. **Minimalism** — remove anything that doesn't help users see the times

## Accessibility & Inclusion

- Responsive for mobile (most users likely access via phone)
- High contrast text for outdoor readability
- Simple, clear time formatting
